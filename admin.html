Topper Vault — Admin

Replace the live index.html on GitHub with a new file. This calls your Vercel backend, which commits the file to your GitHub repo — GitHub Pages then redeploys automatically (usually within a minute).

Size note: Vercel serverless functions cap request bodies at roughly 4.5 MB. Large files (this vault's own index.html can be 10+ MB once real data is imported) may be rejected with a 413 error. For an update that big, push the file with git instead:

git add index.html && git commit -m "update" && git push

Use this page for smaller edits/patches, or raise the limit yourself by proxying the upload through Vercel Blob if you need this routinely for big files.
